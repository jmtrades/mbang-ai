# MGO course map

A catalogue of the Master Growth Operating course on Kajabi, by lesson title only, and where each topic lives in Operator AI.
It holds no course content. To make the app answer from these lessons, the owner exports the files and places them in
`inputs/` as described in the README; the app then cites each lesson by title and timestamp.

Catalogued 2026-10-28 from the member library: 102 lessons in three products.
